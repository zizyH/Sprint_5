\# Sprint\_5 — Автотесты для сервиса «Доска»



UI-автотесты для учебного сервиса https://qa-desk.education-services.ru/ на Python + Selenium + pytest.

## ✅ Покрытые сценарии

### Регистрация пользователя

| ID | Сценарий | Ожидаемый результат |
|---|---|---|
| 1 | Успешная регистрация с валидными данными | Переход на главную, в шапке отображается имя «User» |
| 2 | Регистрация с email не по маске | Под полем Email появляется сообщение «Ошибка» |
| 3 | Регистрация с уже существующим email | Под полем Email появляется сообщение «Ошибка» |

### Login пользователя

| ID | Сценарий | Ожидаемый результат |
|---|---|---|
| 4 | Успешный вход с валидными данными | Переход на главную, отображается имя «User» |

### Logout пользователя

| ID | Сценарий | Ожидаемый результат |
|---|---|---|
| 5 | Выход из аккаунта | Имя «User» скрыто, отображается кнопка «Вход и регистрация» |

### Создание объявления

| ID | Сценарий | Ожидаемый результат |
|---|---|---|
| 6 | Создание объявления неавторизованным | Модальное окно «Чтобы разместить объявление, авторизуйтесь» |
| 7 | Создание объявления авторизованным | Объявление отображается в блоке «Мои объявления» |
